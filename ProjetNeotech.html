NeoTech Inventory : Application de gestion de stock en C# / WinForms

NeoTech Inventory est un projet de spécialité développé dans le cadre du BTS SIO option SLAM (Fiche E6 n°2). Il s'agit d'une application de bureau (client lourd) conçue pour l'entreprise fictive NeoTech Informatique, spécialisée dans la maintenance et la vente de matériel informatique.

L'application remplace une gestion sur tableurs Excel par une solution centralisée reposant sur une base de données SQLite locale. Elle intègre un système d'authentification sécurisé, une interface de gestion CRUD complète (produits, fournisseurs, catégories) et un module de traçabilité des mouvements de stock (entrées/sorties).

Le point fort du projet est son système d'alertes visuelles automatiques : dès qu'un produit passe sous son seuil de stock personnalisé, une mise en évidence par code couleur avertit immédiatement le gestionnaire, facilitant ainsi le réapprovisionnement proactif. L'application repose sur une architecture en couches et a été développée sous Visual Studio 2022 sur MacBook Pro avec virtualisation Windows via Parallels Desktop.
